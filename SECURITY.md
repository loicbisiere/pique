# Security policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue: use **[Report a vulnerability](https://github.com/loicbisiere/toothpeek/security/advisories/new)** (GitHub private vulnerability reporting). I will answer as soon as I can; this is a personal project maintained in my spare time.

Useful to include: what an attacker could do, the steps to reproduce, and the Toothpeek and macOS versions.

## Supported versions

Only the [latest release](https://github.com/loicbisiere/toothpeek/releases/latest) receives fixes.

## Scope

In scope: the Toothpeek app and its build and release pipeline in this repository.

Out of scope: Bambu Lab printers, their firmware and Bambu's cloud services; please report those to Bambu Lab.

How Toothpeek protects the printer access code is described in the [README](README.md#security) and in [docs/protocol.md](docs/protocol.md#verifying-the-printer).
